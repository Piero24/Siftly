# Dashboard Overview

The Siftly dashboard is your central command center for tracking job applications.

## Navigation

The sidebar provides access to all sections:

| Section          | Description                                     |
| ---------------- | ----------------------------------------------- |
| **Overview**     | KPIs, charts, analytics, and world map          |
| **Applications** | Full table of all job applications              |
| **Interviewing** | Applications currently in interview stage       |
| **Settings**     | App configuration, CV profiles, data management |
| **Account**      | Profile info and sign-out                       |

## KPI Strip

At the top of the Overview, a strip of key performance indicators shows:

- **Total Applications** — all-time count
- **Interviewing** — currently active interviews
- **Offers** — received offers
- **Response Rate** — percentage of applications that received a response

## Charts & Analytics

The dashboard includes interactive charts:

- **Application Timeline** — applications over time
- **Status Funnel** — conversion from applied → interviewing → offer
- **Work Type Distribution** — remote / hybrid / onsite breakdown
- **Salary Distribution** — salary ranges across applications
- **Top Companies** — most-applied companies
- **World Map** — geographic distribution of applications

## Time Range Filter

All analytics support time range filtering:

- Today
- Last 7 days
- Last 30 days
- Last year
- All time (Total)

The default time range can be configured in Settings → Appearance.
