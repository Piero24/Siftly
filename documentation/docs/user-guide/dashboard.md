# Dashboard Overview

The Siftly dashboard is your central command center for tracking job applications.

## Navigation

The sidebar provides access to all sections:

| Section          | Description                                     |
| ---------------- | ----------------------------------------------- |
| **Overview**     | KPIs, charts, analytics, and world map          |
| **Applications** | Full table of all job applications              |
| **Interviewing** | Applications currently in interview stage       |
| **Settings**     | App configuration, CV profiles, data management |
| **Account**      | Profile info and sign-out                       |

## KPI Strip

At the top of the Overview, a strip of key performance indicators supports two modes:

- **Current mode**
  - Shows **Total** plus direct status counts (Applied, Interviewing, Offers, Declined, Accepted, Rejected, Pending, No Response).
  - Each counter reflects only the applications currently in that exact status.
- **Total mode**
  - Hides the **Total** card.
  - Uses cumulative pipeline counters:
    - **Applied** = all applications in timeframe (including pending)
    - **Interviewing** = interviewing + offers + declined + accepted + rejected
    - **Offers** = offers + declined + accepted
    - **Declined**, **Accepted**, **Rejected**, **Pending**, **No Response** remain direct counts

## Charts & Analytics

The dashboard includes interactive charts:

- **Application Timeline** — applications over time
- **Status Funnel** — conversion from applied → interviewing → offer
- **Work Type Distribution** — remote / hybrid / onsite breakdown
- **Salary Distribution** — salary ranges across applications
- **Top Companies** — most-applied companies
- **World Map** — geographic distribution of applications

## Time Range Filter

The time range selector applies to both KPI modes and all analytics:

- Today
- Last 7 days
- Last 30 days
- Last year
- All time

Both defaults can be configured in Settings → Appearance:

- Default KPI mode: **Total** or **Current**
- Default Time Range: **Today**, **Last Week**, **Last Month**, **Last Year**, **All Time**
