# Interview Tracking

The **Interviewing** section provides a dedicated view for applications currently in the interview stage.

## Interviewing View

Navigate to **Interviewing** in the sidebar to see a filtered table of all applications with status `interviewing`. This view shows:

- Company and position
- Interview round count
- Next scheduled interview
- Recruiter contact info

![Interviewing table view](/img/screenshots/interviewing-table.png)

## Managing Interview Rounds

Each application can have multiple interview rounds. To manage them:

1. Open an application in the `interviewing` status
2. Scroll to the **Interview Rounds** section
3. Click **Add Round** to create a new round

![Interview rounds inside application detail](/img/screenshots/job-card.png)

### Round Details

Each round includes:

| Field                   | Description                           |
| ----------------------- | ------------------------------------- |
| **Round Number**        | Automatically incremented             |
| **Date & Time**         | When the interview is scheduled       |
| **Interviewer Name**    | Who you'll be speaking with           |
| **Interviewer Contact** | Email or phone (optional)             |
| **Meeting Link**        | Video call URL (optional)             |
| **Location**            | Physical address if onsite (optional) |

## Recruiter Contacts

Each application can have a recruiter attached:

- **Name** — recruiter's full name
- **Email** — direct email address
- **Phone** — phone number

This is separate from the referral contact and can be edited in the application detail modal.

## Next Interview Display

The interviewing view highlights the **next scheduled interview** for each application, showing the date, time, and interviewer name for quick reference.
