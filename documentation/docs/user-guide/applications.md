# Managing Applications

## Adding an Application

1. Click the **+ New Application** button in the top bar.
2. Fill in the details:
   - **Company** and **Position** (required)
   - **Location** — country and city
   - **Work Type** — remote, hybrid, or onsite
   - **Employment Type** — permanent, intern, or fixed-term
   - **Salary** — amount and currency
   - **Status** — pending, applied, interviewing, offer, rejected, no-response
   - **Links** — job posting URL, profile or portal link (LinkedIn, Indeed, etc.), company website
   - **CV Profile** — which CV version you used
   - **Rating** — your personal rating of the opportunity
3. Click **Save**.

## Editing an Application

Click any row in the applications table to open the detail modal. From here you can:

- Edit all fields
- Add/update the job description (supports Markdown)
- Add notes
- Manage referral and recruiter contacts
- Track interview rounds

![Application detail modal](/img/screenshots/job-card.png)

## Changing Status

You can change an application's status in two ways:

- **Quick**: Use the status dropdown directly in the table row
- **Detail**: Open the application modal and change the status field

## Deleting an Application

Open the application detail modal and click the **Delete** button at the bottom. This action requires confirmation.

## Search & Filter

Use the search bar to filter applications by company, position, city, or sector. The table header also provides column-specific sorting.
