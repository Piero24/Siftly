# Theming and Settings

## Theme modes

Supported modes:

- Light
- Dark
- System (follows OS preference)

Theme resolution is applied at document level using `data-theme`.

## Styling system

- Global color/surface tokens in `src/styles/tokens.css`
- Component styles consume tokens for dark/light compatibility
- Shared glass/button/table/modal styles live under `src/styles`

## Settings behaviors

Settings panel currently handles:

- Appearance theme mode
- Localization options
- Automation options
- Dashboard defaults
- CV profile presets
