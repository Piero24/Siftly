# Getting Started

## Prerequisites

- Node.js 20+
- npm 10+

## Install dependencies

From the repository root:

```bash
npm install --legacy-peer-deps
```

For docs site dependencies:

```bash
cd docs-site
npm install
```

## Run the app

```bash
npm run dev
```

## Run documentation locally

```bash
npm run docs:dev
```

## Build checks

```bash
npm run build
npm run test:run
npm run docs:build
npm run format:check
```
