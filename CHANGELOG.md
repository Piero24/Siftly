# Changelog

All notable changes to Siftly will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-04-16

### Added

- **First Official Public Release**
- **Architecture**: Implemented a "Thin Orchestrator" pattern for React components.
- **Platform**: Support for both Chrome Extension (Supabase remote) and Self-Hosted Web App (SQLite local).
- **Dashboard**: Full analytics suite with world maps, funnel charts, and KPI tracking.
- **Job Applications**: Rich management interface with detail modals, bulk status updates, and filtering.
- **Interviews**: Comprehensive interview tracking with round-by-round status and automated follow-up logic.
- **Security**: Supabase Auth (OAuth) and local profile management.
- **Automation**: Draggable extension panel, auto-close timers, and "No Response" automation.
- **Portability**: CSV import/export for full data ownership.
- **Documentation**: Comprehensive User and Developer guides via Docusaurus.
- **CI/CD**: Full automated pipeline for linting, testing, and multi-target builds.
